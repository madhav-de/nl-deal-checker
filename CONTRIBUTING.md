# Contributing

Thanks for helping keep nl-deal-checker accurate. Dutch shops, rules and promotions change often, so corrections are very welcome.

## Good contributions

- A new trap you ran into (with an example)
- A rule or term that changed (with a link to an official source)
- Clearer wording in `SKILL.md`
- Glossary additions

## Ground rules

1. **Cite sources** for legal or consumer-rights claims. Prefer official sites (Rijksoverheid, ACM, ConsuWijzer, Belastingdienst) over blogs.
2. **No shop prices in `SKILL.md`.** They go stale within days. Describe the check, not today's price.
3. **No affiliate links or shop promotion.** The skill must stay neutral.
4. **No scripts or code.** The skill stays a plain instruction file, so anyone can read exactly what it tells Claude to do.
5. **Keep it short.** Every line in `SKILL.md` costs context when Claude loads it.

## How to contribute

1. Fork the repo and create a branch.
2. Make your change and update `CHANGELOG.md` under "Unreleased".
3. Open a pull request using the template.

For small fixes (typos, a glossary word) an issue is fine too.

## Security issues

Do not open a public issue. See [SECURITY.md](SECURITY.md).
